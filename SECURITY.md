# Security and publication boundary

This repository is a portfolio-safe reimplementation using a synthetic `.eml` fixture. It is not the original internal or employer-owned application.

Do not add:

- employer source code, private integrations, or internal rule formats;
- real customer messages, addresses, case identifiers, or mailbox exports;
- internal headers, hostnames, IP addresses, endpoints, credentials, tokens, or logs;
- proprietary prompts, models, taxonomies, enrichment logic, or screenshots;
- files that contain production data or private filesystem paths.

The demo performs local parsing and uses a deterministic mock provider. It makes no network requests and does not make automatic production decisions. Use synthetic fixtures or data you are authorized to process. Review employment, confidentiality, and intellectual-property obligations before publishing.
